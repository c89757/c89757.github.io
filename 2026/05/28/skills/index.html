工作流

superpower-brainstorming

https://github.com/obra/superpowers/blob/main/skills/brainstorming/SKILL.md

在 任何实现工作开始之前，强制性地引导 AI 与用户完成从想法到可执行规格说明的完整设计对话流程。它通过一个硬性门禁（Hard Gate）规定：

在向用户展示设计方案并获得明确批准之前，不得编写任何代码、生成项目或执行实现动作，无论项目看起来多简单。

流程概览

  1. 探索项目上下文 — 了解当前代码状态
  2. 提出澄清问题 — 一次一个，逐层细化需求
  3. 给出 2-3 种方案 — 附带权衡分析和推荐
  4. 逐节呈现设计 — 每节获得用户确认后再继续
  5. 撰写设计文档 — 保存到 docs/superpowers/specs/ 并提交
  6. 规格自审 — 检查占位符、矛盾、歧义
  7. 用户审核规格文件 — 批准后才进入实现阶段
  8. 调用 writing-plans skill — 从设计过渡到实现计划

awesome-design-md

https://github.com/VoltAgent/awesome-design-md

DESIGN.md 是 Google Stitch 提出的一种概念——一个纯文本的设计系统文档，AI Agent 通过它来理解界面应该如何呈现。它和 AGENTS.md 是互补的：

  • AGENTS.md → 告诉 Agent 怎么构建项目
  • DESIGN.md → 告诉 Agent 界面该长什么样

内容规模

目前收录了 73 个已分析的知名网站，按类别排列：

分类 示例
AI & LLM 平台 Claude、Cohere、Mistral、Ollama、xAI
开发者工具 Cursor、Vercel、Warp、Expo
后端 & DevOps MongoDB、Supabase、Sentry、ClickHouse
生产力 & SaaS Notion、Linear、Intercom、Mintlify
金融 & 加密货币 Stripe、Coinbase、Binance、Revolut
电商 & 零售 Shopify、Airbnb、Nike、Starbucks
媒体 & 消费电子 Apple、Spotify、NVIDIA、SpaceX
汽车 Tesla、Ferrari、BMW、Lamborghini

每个设计文件包含的内容

  1. 视觉主题与氛围 — 情绪、密度、设计哲学
  2. 调色板与角色 — 语义名 + hex + 功能角色
  3. 排版规则 — 字体族 + 完整的层级表
  4. 组件样式 — 按钮、卡片、输入框、导航（含状态）
  5. 布局原则 — 间距体系、网格、留白哲学
  6. 深度与层级 — 阴影系统、表面层级
  7. Do’s and Don’ts — 设计护栏和反模式
  8. 响应式行为 — 断点、触摸目标、折叠策略
  9. Agent Prompt 指南 — 即用的 prompt 模板

ui-ux-pro-max-skill

https://cn.x-cmd.com/skill/nextlevelbuilder/ui-ux-pro-max-skill

一套综合性的 UI/UX 设计知识库与设计决策引擎。

核心作用

当 AI 需要处理任何与视觉界面、交互设计、用户体验相关的任务时，它提供结构化、可查询的设计指导，确保产出在专业性、可访问性、一致性方面达到工程标准。

它包含什么

  • 50+ 设计风格（毛玻璃、黏土风、极简主义、新拟态等）
  • 161 个配色方案 + 57 种字体搭配
  • 99 条 UX 准则（覆盖 10 个优先级层级）
  • 25 种图表类型建议
  • 10 种技术栈落地指导（React、Next.js、Vue、Svelte、SwiftUI、Flutter、Tailwind 等）
  • 配套 CLI 搜索工具 — 通过 search.py 脚本按 domain 查询（如 --domain color、--domain ux）

web-design-guidelines

这个 skill 来自 vercel-labs/agent-skills 仓库，是一个 UI 代码审计工具。

核心作用

对指定的 UI 代码文件进行合规性审查，检查是否满足 Web 界面最佳实践。它会拉取最新的规则集，然后扫描你的代码，输出具体的违规位置和问题。

工作方式

  1. 获取规则 — 从外部 URL 拉取最新的 Web 界面指南（100+ 条规则）
  2. 读取文件 — 读取用户指定的文件或模式
  3. 逐条检查 — 对照所有规则进行检查
  4. 输出结果 — 以 file:line 格式输出发现的问题

审计覆盖范围（从 README 信息看）

  • 可访问性（Accessibility）
  • 性能（Performance）
  • UX 质量（UX quality）

触发时机

用户说以下内容时使用：

  • “review my UI” / “audit design”
  • “check accessibility”
  • “review UX”
  • “check my site against best practices”

frontend-design-pro

这个 skill 来自 https://smithery.ai/skills/claudekit/frontend-design-pro，是一个视觉导向的前端实现指令集，由 Smithery 平台托管，支持 20+ 种 AI 编程工具。

核心作用

教 AI 像顶级设计Agency一样直接写出惊艳的前端代码，而不是提供设计规则或流程。它要求 Agent 在实现时就必须达到”5万美金项目”的视觉水准。

它包含什么

12 种预设美学方向，每个方向有明确的配色关键词、核心效果：

风格 关键词
极简瑞士风 网格、留白、字体驱动
新拟态 柔和阴影、凹凸感、单色系
毛玻璃 模糊、透明、发光边框
粗野主义 原始、不对称、高对比
黏土风 3D、玩具感、糖果色
极光渐变 霓虹、流动、半透明
赛博朋克 霓虹发光、扫描线、故障效果
3D 超写实 WebGL、物理运动、金属质感
大胆极繁 色块、双色调、戏剧化
暗黑 OLED 纯黑、微光、电影感
有机/生物形态 流体形状、不规则边框
图片系统 提供 Unsplash 直链 + AI 图片 prompt

非协商规则（硬性要求）

  • 禁止使用 Inter、Roboto、Arial 等默认字体 — 必须用有个性的字体
  • CSS 变量全局管理
  • 一个主色 + 锐利的强调色
  • 必须有一个难忘的视觉签名（噪点纹理、自定义光标、动画网格等）
  • 打破居中卡片网格 — 不对称、重叠、对角线流动
  • 完整 WCAG AA/AAA 无障碍支持
  • 每张图片必须是真实照片或完美的 AI prompt，不能编造

输出

直接给生产级、可复制粘贴的代码（HTML + Tailwind/CSS、React、Vue 等），带完整响应式和性能优化。
